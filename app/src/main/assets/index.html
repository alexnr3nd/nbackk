Como jogar

Em cada tentativa, observe os estímulos. Pressione o botão de uma modalidade quando o estímulo atual for igual ao apresentado N tentativas atrás. Se não houver correspondência, não pressione.

Dual: posição + som/letra. Triple: adiciona cor. Quad: adiciona forma. O som é sintetizado no próprio aparelho; não depende de internet.

A rodada avalia acertos, omissões e falsos alarmes por modalidade. Velocidade é calculada pelo tempo total da rodada. O recorde é o maior N-back concluído com pelo menos 70% de precisão geral.
